# Shadow Devour — authored solid-cocoon implementation

Owner-authorized against `1c55239cb51dd44727ea75b70f4aab6a6e208a48`. AICP 1.2.1 / UGDS 1.0.0 remain pinned. Playable implementation delivered for owner visual acceptance.

The four poses are extracted directly from the authored solid-cocoon sheet, despite its legacy hollow-envelope filename. SVG near-black becomes opaque pure black. Upper contours are sampled and interpolated into 29 editable keyframes (20 ms sampling plus terminal pose), with transparent PNG exports. Timing: rest 0 ms, unfold 80 ms, full cocoon 160 ms, hold through 260 ms, settle 420 ms, identical rest at 560 ms. It is a fast 160 ms expansion, 100 ms full hold, then contraction. This is presentation duration only; engine assassination still resolves immediately. Cooldown stays 1.2 s; ordinary Spike stays 220 ms/range105.

The renderer retains the last upright guard frame before logical defeat and displays it from the same input/render turn as Devour starts. An irregular directional luminance mask removes guard alpha from 60–260 ms; independent black cocoon geometry also occludes it. At full masking, the guard wrapper, including its ground-shadow ellipse, is explicitly hidden, remaining hidden after contraction. The mask uses a broad target-independent coordinate field, not a guard-shaped hole. Cocoon is solid with no internal cutout. Source ground y232 maps to player ground; uniform scale grows from the existing 0.4321 to0.65 and an affine directional lean aims the authored silhouette toward the target while its ground pivot stays fixed. This is geometric presentation, not Shadow Expansion or a mass-conservation mechanic.

Movement or terminal phase cancels the presentation and hides the already defeated guard; pause/help freeze on engine simulation time; restart/new game clears the mask and restores a live guard. No walking, damage, eligibility, health, range, control or engine changes. New integrated motion needs owner visual acceptance.

## Reproduce

Existing checkout; no worktree needed. `npm ci --no-audit --no-fund`; `python3 scripts/devour/prepare.py`; `node scripts/devour/export.mjs`; `npm run build`; `npm start`. Use installed Chromium, Python standard library/Pillow and FFmpeg only. Guard and existing Spike exports need not be regenerated.

`LAB_VALIDATION_DIR=/workspace/devour-validation node scripts/laboratory/run-validation.mjs` runs the original full gameplay assertions with recording hooks, storing outputs outside historical evidence. `python3 scripts/devour/verify.py`, `node scripts/devour/check.mjs`, `node scripts/devour/mask-inspect.mjs`, `node scripts/devour/preview-check.mjs` exercise targeted behavior. To record the full effect without immediately moving away, run `scripts/devour/record.mjs` from a separate empty directory containing `evidence/`; copy resulting media into a new evidence folder. `EVIDENCE_DIR=evidence/devour python3 scripts/laboratory/package.py` packages dist. Processes do not survive task restoration; start the local server again. The ZIP is a local static build, not a deployed website.

## Visual limits / owner gate

The solid silhouette and four authored shape directions are preserved. In-between contours use 129 sampled upper-outline points; subtle polygonal transitions may be visible at large inspection zoom. The renderer applies scale and directional affine lean toward the eligible target so the authored cocoon covers the encounter while keeping its ground pivot fixed. This is a presentation adaptation, not a second independently invented visual concept; its proportions, lean and 560 ms readability require owner judgment. The first20 ms retains the current box/chair outline when disguised; after the effect the renderer restores the engine's current resting/disguised/moving form. The terminal rest source is exact to the prior approved contour.

The mask is an irregular binary spatial alpha wipe, not a generic uniform opacity fade. Cocoon stays fully opaque black. Some target pixels can remain at the outer edge during intermediate wipe stages; none remain after260 ms or reappear on contraction. No target-shaped hollow is used, and no dead guard is reinserted into the corpse renderer after consumption. Immediate logical defeat is preserved; the rendered guard temporarily remains upright solely as presentation. Pause/help freeze simulation-time presentation; movement and terminal states cancel it, hiding an already defeated target. Restart/new game clears consumed/mask state and presents the living guard. No logical delay, movement lock, invulnerability, additional range/target, damage, health or awareness rule.
